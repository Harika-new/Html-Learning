# 🍽️ Recipe Gallery – HTML Project

## 📄 Project Summary
A beginner-friendly HTML project that displays a recipe gallery using only HTML tables. Each image links to a full recipe page, demonstrating basic layout and linking concepts.

## 📚 What I Learned
- How to use `<table>`, `<tr>`, and `<td>` for layout
- Embedding and linking images using `<img>` and `<a>`
- Applying simple inline styles for formatting
- Building clean HTML structure **without any CSS**

## 🚧 Challenges I Faced
- Aligning multiple items side-by-side without using CSS
- Centering content using only HTML attributes like `align`
- Keeping the layout visually balanced using just HTML tables

## ✅ Features
- Displays **three recipes** in a single row: Pasta, Pizza, and Burger
- Each recipe block includes a heading, an image, and a clickable link to the recipe
- Fully semantic and clean HTML-only structure with no external styling

## 📝 Note
This project was created to strengthen my understanding of core HTML concepts before moving on to CSS or advanced layout tools.
